# Machine Learning Module — TripWise

This module handles:
1. `dataset/`: Synthetic dataset generation scripts & CSV storage.
2. `notebooks/`: Exploratory Data Analysis (EDA) & baseline model comparisons (Linear Regression vs Random Forest vs Gradient Boosting).
3. `models/`: Trained Scikit-Learn `.joblib` model artifacts.
4. `train.py`: Reproducible training script for generating final model pipelines.
